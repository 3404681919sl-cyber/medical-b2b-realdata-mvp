# 需求预测策略选择与 BadCase 口径

## 目的

本模块用于比较简单、可解释的周需求预测基线，而不是声称已经训练出可直接用于中国药店采购的生产模型。候选策略使用三折扩展窗口滚动回测，避免只依赖一个有利的测试窗口。

## 候选策略

系统完整遍历以下候选，而不是对非单调的模型选择问题使用二分搜索：

- 朴素预测：未来各期等于最近一期需求。
- 移动平均：分别比较最近 4、8、12 周均值。
- 季节性朴素：分别比较 4 周和 13 周周期，按最近一个完整周期循环预测。
- Croston-SBA：分别比较 `α=0.1/0.2/0.3`，用于间歇需求并进行偏差修正。

当前公开数据仅覆盖 2015 年，因此不使用 52 周年度季节性策略；训练历史不足时也不会强行纳入对应周期。

## 评价与推荐规则

1. 使用三个连续的 4 周测试折，训练窗口随时间扩展，共评估 12 周。
2. 每个候选聚合三个测试折的绝对误差，输出 MAE 与 WAPE。
3. 自动推荐按 `WAPE → MAE → candidate_id` 依次升序选择。
4. 用户可以人工选择其他策略，但系统保留自动推荐，不覆盖原始结果。
5. 每次选择均可导出 JSON 决策记录，包含数据时间范围、滚动折数、候选表、选择规则、自动推荐和人工选择。

这一设计沿用既有研究工作中的可复现原则：保留完整候选结果，同时区分自动评分与人工业务判断。

## 可预测覆盖率

覆盖率按 SKU 计算，不按交易行数计算。SKU 同时满足以下条件时计入“可完整回测”：

- 至少有 21 周历史，以保证 8 周留出后仍可比较 13 周季节性基线；
- 最后 8 周的实际需求绝对值之和不为 0，使 WAPE 有定义。

## BadCase 标签

| 代码 | 含义 | 是否阻断完整回测 |
|---|---|---|
| `SHORT_HISTORY` | 历史不足 21 周 | 是 |
| `ZERO_HOLDOUT_DEMAND` | 最后 8 周需求为 0，WAPE 无定义 | 是 |
| `SPARSE_DEMAND` | 非零需求周占比低于 25% | 否，作为风险提示 |
| `HIGH_VARIATION` | 周需求变异系数高于 2 | 否，作为风险提示 |

## 当前真实数据快照

基于当前标准化交易表重新计算：

- 已售 SKU：2,042；
- 可完整回测 SKU：1,361，覆盖率 66.65%；
- 历史不足 21 周：681；
- 稀疏需求：451；
- 高波动需求：527；
- 测试期需求为 0：0。

风险标签可重叠，因此各类数量不能直接相加。该快照必须在数据源或阈值改变后重新计算。

## 证据边界

- 销量为 0 不等于断货。公开数据没有库存、缺货、效期或促销字段，因此系统不推断断货原因。
- 历史回测误差不等于未来真实门店效果。
- 自动推荐只是统计策略选择，不替代采购人员对供应商、库存和促销信息的判断。
- Croston-SBA 只处理销量的间歇性，不代表系统知道零销量来自缺货还是无需求。
